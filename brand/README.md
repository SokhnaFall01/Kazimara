# Identité visuelle Kazimara

| Fichier | Usage |
|---|---|
| `kazimara-logo.svg` | Logo horizontal, fond clair |
| `kazimara-logo-sombre.svg` | Logo horizontal, fond sombre (pilier crème, slogan or) |
| `kazimara-symbole.svg` | Symbole seul : icône d'application, favicon, petites tailles |

## Ce que raconte le symbole

- **Le pilier** — « imara », la solidité. Chevrons inspirés des tissus bogolan, qui montent comme la progression.
- **Les briques** — « kazi », le travail. L'entreprise se bâtit brique par brique.
- **Le soleil** — la réussite, au sommet de l'escalier.
- **L'élan** — la jambe du K, posée au sol, qui donne l'équilibre et le mouvement vers l'avant.

## Couleurs

| Nom | Hex | RVB | Sens |
|---|---|---|---|
| Vert baobab | `#1F5C45` | 31 92 69 | Croissance, confiance, durabilité |
| Terre cuite | `#D2662B` | 210 102 43 | Le travail, la terre, l'artisanat africain |
| Or soleil | `#F2B33D` | 242 179 61 | Prospérité, réussite, énergie |

Les valeurs utilisées dans le code sont dans [`packages/ui-tokens`](../packages/ui-tokens/src/index.ts).

> Les SVG sont une reconstitution fidèle de la planche « Identité visuelle · proposition ».
